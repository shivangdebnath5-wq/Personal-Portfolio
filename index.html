Hello!

I'm a student who enjoys designing and coding original ideas.

I'm Shivang Debnath. What started as simple curiosity about how websites and apps are made quickly turned into one of my favorite things to do. Instead of just copying templates, I enjoy coming up with my own project ideas and figuring out how to build them step by step.

Whether I'm designing a chat platform like Nexora Chat, sketching an illustrated Virtual Supermarket, or thinking about how a civic road-reporting app like Raasta could work in India, I love combining clean code with thoughtful design.

01 • Why I Build

Turning Ideas Into Reality

The best feeling is starting with a blank file or a rough sketch in my notebook and watching it turn into something people can actually click and use on their screen.

02 • Design & Code

Caring About the Details

I care just as much about how a project looks and feels as how the code works behind the scenes. Good spacing, readable fonts, and smooth transitions make a big difference.

03 • My Mindset

Always Learning

Every project teaches me something new. Whenever I run into a bug or a tricky layout problem, I treat it as a puzzle to solve and a chance to improve.

04 • My Interests

What Inspires My Work.

Outside of schoolwork, I spend most of my free time exploring technology, practicing interface design, and listening to music while I build.

01 • Technology Web & Software

Exploring How the Web Works

I enjoy learning how modern browsers, code editors, and web tools work together. Whenever I see an interesting feature on a website, I like inspecting how it was built and trying to write my own clean version using HTML, CSS, and JavaScript.

Click a topic to see why I enjoy it: Frontend Code

Building clean page structures that work smoothly on both laptops and phones without unnecessary clutter.

"Technology is exciting because anyone with a laptop and curiosity can build something useful from scratch."

02 • Design UI/UX & Visual Style

Interface Design & Typography

Good design makes software feel welcoming and easy to understand. I love experimenting with dark-mode color palettes, pairing expressive serif headings with clean sans-serif text, and organizing layouts so nothing feels confusing.
